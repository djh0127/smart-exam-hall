# smart-exam-hall
基于 Qt + C++ + OpenCV 实现的智能考场监控系统，利用机器视觉完成考场违规行为识别。

## 技术栈
- C++
- Qt
- OpenCV
- 多线程
- 图像采集、图像处理

## 项目简介
对接摄像头实时读取考场画面，通过OpenCV做图像预处理、目标检测，识别考场内疑似作弊行为，实时弹窗告警并保存违规截图。

## 核心功能
1. 摄像头实时视频流读取与画面展示
2. 图像灰度化、滤波、轮廓检测等预处理
3. 人脸检测、人体检测
4. 异常行为识别（低头、转头、多人同框等考场作弊场景）
5. 违规截图自动保存
6. 多线程处理视频流，防止UI界面卡顿

## 编译环境

- OpenCV 配置到Qt工程
